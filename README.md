# Praveen Redapongu: GitHub Pages site

Two things go online: `index.html` and the `assets` folder (holding `praveen-portrait.jpg`).
Keep them together, with `assets` sitting next to `index.html`.

## Put it online (about 10 minutes)

1. Sign in at github.com (create a free account if you need one).
2. Click **New repository**. Name it `praveen-redapongu`, set it to **Public**, and click **Create repository**.
3. On the new repo page, click **uploading an existing file**.
4. Drag in `index.html` and the whole `assets` folder. Click **Commit changes**.
5. Go to **Settings, then Pages**. Under "Build and deployment", set Source to **Deploy from a branch**, Branch to **main**, folder to **/ (root)**, and click **Save**.
6. Wait about a minute and refresh. GitHub shows your address:
   `https://<your-username>.github.io/praveen-redapongu/`
7. Open that address in a private or incognito window to confirm it loads without any sign-in.

Tip: if you name the repository `<your-username>.github.io`, the address becomes just `https://<your-username>.github.io/`, which is shorter for LinkedIn.

## Update it later

Open the repo, click `index.html`, click the pencil icon, change the text, and click **Commit changes**. The site refreshes in about a minute. To add a project, copy one `<article>...</article>` card inside the Flagship projects section and edit the words. To add a milestone, copy one row in the Latest updates section.

To change the photo, upload a new image to `assets` with the same name `praveen-portrait.jpg`.

## Two links to set before you share it

- **Topmate button:** in `index.html`, search for `https://topmate.io` and replace it with your own Topmate profile URL. Also delete the small grey line next to the button that says to replace it.
- **LinkedIn:** once the site is live, add the address to your About section, Contact info and Featured.

## Later: your own domain

Buy a domain such as `praveenredapongu.com` (roughly 800 to 1,200 rupees a year), then add it under Settings, then Pages, then Custom domain, and follow GitHub's DNS instructions.
